# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built to showcase my projects, technical skills, and journey as a Computer Science student.

---

## 📌 About the Project

This portfolio is designed to represent my profile as a developer, highlight my work, and provide an easy way to connect with me.

It features a clean UI, smooth animations, and a structured layout to ensure a professional user experience across all devices.

---

## ✨ Features

* 🌙 Dark / Light mode toggle (with localStorage persistence)
* 🎨 Modern UI with glassmorphism design
* 📱 Fully responsive (mobile, tablet, desktop)
* ⚡ Smooth scroll and reveal animations
* 🎯 Interactive hero section with typing effect
* 📊 Skills section with animated progress bars
* 🧩 Project showcase with GitHub links
* 📬 Contact section with direct email access
* 🎥 Canvas-based animated particle background

---

## ⚙️ How It Works

### 1. Theme Toggle

* Users can switch between dark and light mode
* Preference is stored using `localStorage`
* Automatically loads saved theme on refresh

### 2. Scroll Animations

* Uses `IntersectionObserver`
* Elements appear with smooth transitions when visible

### 3. Typing Effect

* JavaScript simulates typing and deleting text
* Cycles through multiple phrases dynamically

### 4. Skill Progress Bars

* Bars animate only when section enters viewport
* Width controlled via `data-width` attribute

### 5. Particle Background

* Built using HTML `<canvas>`
* Animated particles move and connect dynamically

### 6. Responsive Design

* Flexbox + Grid used for layout
* Media queries ensure proper display on all devices
